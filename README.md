# Wartales-MP Launcher

Лаунчер и установщик кооперативного мода [wartales-mp](https://github.com/UberMorgott/Wartales-Mod-wartales-mp) для Wartales.

> Неофициальный проект. Не связан с Shiro Games и автором мода.

## Скачать

Последняя версия — на странице [Releases](https://github.com/victor-koval/wartales-mp-launcher-releases/releases/latest): файл `WartalesMP-Launcher.exe`.
Запускайте из любой папки, установка не нужна. Дальше лаунчер обновляется сам.

Нужен .NET Framework 4.5+ — он уже есть в Windows 10 и 11.

## Что умеет

- Запуск игры через Steam, показывает, с какой версией мода она стартует.
- Установка, обновление, откат и удаление мода с проверкой SHA256.
- Резервная копия сохранений перед каждой установкой мода; окно «Копии сохранений» для восстановления.
- Код лобби из лога мода с кнопкой «Копировать» — хост сразу отправляет его друзьям.
- «Остаться на этой версии» — если компания договорилась играть на одной версии мода.
- Предупреждает о версиях, которые автор мода просит не использовать, и об обновлении игры после установки мода.

## Предупреждение Windows SmartScreen

Файл не подписан цифровой подписью, поэтому при первом запуске Windows может показать «Система Windows защитила ваш компьютер».
Нажмите «Подробнее» → «Выполнить в любом случае».

Проверить, что файл не изменён: в PowerShell выполните

```powershell
Get-FileHash .\WartalesMP-Launcher.exe
```

и сравните результат с SHA256 в описании релиза.
